Project Description

VALOBLOX is a frontend prototype for a web-based installment management system for Maryanne's online shop. It is designed to provide an organized and user-friendly interface for managing customer applications, installment information, payments, and notifications.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Figma
- Visual Studio Code
- GitHub

Setup Instructions

1. Clone or download the "credit-installment-monitoring-system" repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files and folders are in their correct locations.
4. Open "index.html" in a web browser.
5. Use the navigation and buttons to access the implemented pages.

No additional installation or build process is required because VALOBLOX is a frontend project using HTML, CSS, and JavaScript.
